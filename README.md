# banana-prompt-kit

Small prompt pack + checklist helpers for **Banana Pro AI** (`https://bananaproai.app/`).

## What's inside
- `prompts/starter.txt` — reusable prompt templates (product, thumbnail, character)
- `CHECKLIST.md` — prompt → image shipping checklist

## Quick start
1. Copy a template from `prompts/starter.txt`
2. Fill the brackets
3. Generate at [Banana Pro AI](https://bananaproai.app/)
4. Save the winning prompt next to your export
